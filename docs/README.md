# Knowii Community

Take part in the [Knowii community](https://www.store.dsebastien.net/product/knowii-community/) without leaving your vault. The plugin opens the community in a pane inside Obsidian: feed, spaces, questions, notifications, direct messages and events, right next to your notes.

## Key features

- The whole community in a pane, as a main tab or docked in a sidebar
- Sign in once; the pane remembers you across restarts
- A toolbar with navigation and shortcuts to the feed, messages, notifications, events and members
- Commands for the palette and hotkeys
- Reopens the page you were on
- Zoom for narrow sidebars

## Quick start

1. Install and enable the plugin
2. Click the Knowii icon in the ribbon, or run **Open Knowii**
3. Sign in with your Knowii account
